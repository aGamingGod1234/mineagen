# #269 Add a model-free fight room set

- **Problem:** to know whether the bot fights better, we had to play whole games with the model, hours each, where one bad decision hides whether the body fought well.
  **Solution:** a practice room set that drops the body, with real gear, into 60 fights per pass against every mob that kills it, in the open, in a corridor and on a lava bridge, with no model in the loop.
  **Result:** 180 fights measured in about 30 minutes on 4 machines with 0 model tokens, where a 6-hour real game gives about 5 deaths (42 in 8 fresh games) (measured, one batch on main).
