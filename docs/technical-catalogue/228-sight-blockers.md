# #228 Skip sight rays already stopped by a solid block

- **Problem:** To decide whether a bot can see a block, the server casts up to about 20 rays across it. When the block is hidden, every ray fails, nearly always on the same one or two solid blocks in front of it, and each ray re-traced that whole path. Creatures got the same treatment, with several rays across each one's body.
- **Solution:** Within one check, remember the solid cubes that already stopped a ray. A later ray that passes through the inside of one is answered as blocked without tracing it. Water is also read as see-through directly, without asking the game for its shape on every ray. Every answer stays identical: 600,776 random scenes compared with the old full trace, with no differences.
- **Result:** Sight-ray time per server tick fell on 7 of 7 test machines (measured with Java Flight Recorder, same-batch pairs on large test machines). At 16 bots it went from 4.0 to 1.0 ms, and at 32 bots from 8.1 to 3.2 ms. On a 3-machine ladder, ticks per second went from 15.1 to 18.6 at 16 bots and from 10.3 to 11.6 at 32. The hidden-hillside check ran about 3.4 times faster in a local benchmark. Bots play the same: 90 of 90 practice rooms passed on both sides.
