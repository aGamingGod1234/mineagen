# Security

## Report a vulnerability

Report it privately through the repository's Security tab, on the "Report a vulnerability" page. Do not open a public issue or pull request for it. Include the steps to reproduce it and the version or commit you tested.

## API keys

Mineagen uses your provider CLI login by default. If you save a provider API key in the Agents screen, Mineagen stores it only on the machine that runs the world, readable only by your account, and sends it only to that provider. It is never sent to this project or to anyone else.
